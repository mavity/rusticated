# Mohabbat Redesign: `#![no_std]` Brot Micro-Launchers

Here is the plan to implement the remaining Linux and macOS targets:

---

### Why They Are Currently Missing
Currently, `mohabbat-next/probe/hosts/unix` uses generic Rust `std`. This couples the binary to the host OS's C runtime (glibc for desktop Linux, Bionic libc + NDK for Android, and Xcode SDK for macOS), preventing clean cross-compilation from a single host without multi-gigabyte platform SDKs.

---

### The Plan: Convert Brot into `#![no_std]` Micro-Launchers

We will bring the proven low-level launcher architecture (which current Mohabbat used in `mohabbat/brot/`) into `mohabbat-next`:

#### 1. Low-Level `#![no_std]` Brot Implementation
* **Memory Management**: Add a minimal page-based or bump allocator backed by `mmap` so `ruzstd` (`default-features = false`) has `alloc` available for decompression buffers.
* **Linux (x86_64 & AArch64) & Android (AArch64)**:
  * Implement raw inline assembly syscalls (`open`, `read`, `lseek`, `mmap`, `munmap`, `unlink`, `write`, `exit`).
  * Android uses Linux system calls with static-PIE (`ET_DYN` without `PT_INTERP`), which the Android kernel and Bionic linker accept directly.
  * Target: `x86_64-unknown-linux-musl` and `aarch64-unknown-linux-musl`.
  * **Zero dependency** on glibc, musl host packages, or Android NDK.
* **macOS / Darwin (x86_64 & AArch64)**:
  * Declare minimal external functions from `libSystem` (`open`, `lseek`, `read`, `close`, `mmap`, `munmap`, `unlink`, `exit`, `sys_icache_invalidate`, `pthread_jit_write_protect_np`).
  * Link with `rust-lld -flavor darwin-lld` against the project's minimal `libSystem.tbd` stub.
  * **Zero dependency** on Xcode or macOS SDK.

#### 2. Cross-Compilation in Go Builder (`steps_rust.go`)
* Add a runner build step to `mohabbat-next/build/steps_rust.go`:
  * Invokes Cargo for each of the 5 targets with appropriate `rustflags` (`linker=rust-lld`, `-pie`, etc.).
  * Emits genuine executables:
    * `brot-x86_64-unknown-linux-gnu` (or static musl)
    * `brot-aarch64-unknown-linux-gnu`
    * `brot-aarch64-linux-android`
    * `brot-x86_64-apple-darwin`
    * `brot-aarch64-apple-darwin`
* Validates that all 5 genuine runners are built and published into `probe/hosts/unix/out/`.

#### 3. Vegetable Assembly & Validation
* Run the Go builder **without `--fixture`**: it will require all 5 genuine runners, find them, and produce the final universal vegetable.
* Validate that the resulting vegetable passes:
  * Windows acceptance (`test-windows.ps1`).
  * Linux AArch64 acceptance in WSL (`test_probe.py`).
  * Polyglot assembler acceptance (`test-polyglot-assembler.ps1`).
