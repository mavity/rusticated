# Mohabbat Redesign: Handshake Protocol & Unified Pool Specification

This specification defines the Unix bootstrap-to-Brot handshake protocol using runtime executable basename demarcation, and the unified Zstandard data pool layout.

---

## 1. Handshake Protocol & Basename Demarcation

To make command-line argument passing immune to wrapper injections (such as Android Termux's `libtermux-exec.so` which prepends `/system/bin/linker64` or duplicates `argv[0]`), Brot discovers its own unforgeable randomized basename from the OS kernel and uses it as the demarcation point in `argv`.

### The Natural Shell Invocation
The shell bootstrap does not need artificial sentinel tokens. It executes a completely standard command line:

```sh
exec "$tmp_exe" "$ME" "$POOL_OFFSET" "$POOL_LENGTH" "$@"
```

### Protocol Argument Resolution

1. **Kernel Discovery**:
   On startup, Brot queries the OS kernel for its own executable path:
   * **Linux & Android**: Calls `readlinkat(AT_FDCWD, "/proc/self/exe", buf, len)`.
   * **macOS (Darwin)**: Calls `_NSGetExecutablePath(buf, &len)`.
   This returns the true, canonical path on disk (e.g. `/data/data/com.termux/files/usr/tmp/🐚︎cxUekxaaORnn`).

2. **Immediate Self-Unlink**:
   Brot unlinks the exact path returned by the kernel (`sys_unlink(own_path)`). This is guaranteed to be the temporary launcher, never a wrapper or system binary.

3. **Basename Extraction**:
   Brot extracts the basename from `own_path` (the characters following the last `/`, e.g. `🐚︎cxUekxaaORnn`).
   Because `mktemp` generates this name per run with 12 random characters, **no caller or user command-line argument can ever collide with or guess this basename**.

4. **Demarcation in `argv`**:
   Brot scans `argv[0..argc-1]` to find the **last argument whose basename matches this exact string**.
   * Any wrapper arguments (e.g. `argv[0] = /system/bin/linker64`, duplicate `argv[1] = .../🐚︎cxUekxaaORnn`) are automatically skipped.
   * The argument **immediately following this last match** is guaranteed to be `$ME` (the bundle path).
   * The next argument is `$POOL_OFFSET`.
   * The next argument is `$POOL_LENGTH`.
   * All subsequent arguments are forwarded directly to the application payload as user arguments (`"$@"`).

## 2. The Unified Zstandard Data Pool

Instead of compressing individual ~800-byte components into separate standalone Zstandard frames (which penalizes compression ratio and litters the bootstrap with separate offsets), all movable PAL and runtime binaries are packed into **one contiguous uncompressed chunk** and compressed as **one Zstandard stream**.

### Uncompressed Pool Memory Layout

```
[Pool Header / Table of Contents]
├── Magic: [u8; 8] = b"MOHABBAT"
├── Version: u32 = 1
├── Entry Count: u32
└── Entries[]:
    ├── Component Tag: u32 (e.g. 1=Win-x64, 2=Win-arm64, 3=Linux-x64, 4=Linux-arm64, 5=Darwin-x64, 6=Darwin-arm64, 10=Hello-x64, 11=Hello-arm64)
    ├── Uncompressed Offset: u32
    └── Uncompressed Length: u32

[Raw Machine Code Blobs]
├── Windows PAL binaries
├── Linux PAL binaries
├── Darwin PAL binaries
└── Hello runtime payloads
```

### Decompression Flow
1. Brot seeks to `$POOL_OFFSET` in `$ME` and reads `$POOL_LENGTH` bytes.
2. It decompresses the entire pool in **one single decode pass** into memory.
3. It performs an in-memory index lookup into the decompressed TOC to locate its target-matched PAL and runtime code.
4. It sets up PAL bindings, maps memory, and transfers control.

## 3. Simplified Unix Bootstrap Script (`bootstrap.sh.in`)

With the unified pool and basename demarcation, the shell bootstrap script eliminates all component offset variables and reduces to:

```sh
# No shebang: the MZ DOS stub evaluates this appended script.
set -eu

if command -v realpath >/dev/null 2>&1; then
    ME="$(realpath "$0")"
else
    case "$0" in
        /*) ME="$0" ;;
        *) ME="$PWD/$0" ;;
    esac
fi

SYSTEM="$(uname -s)"
ARCH="$(uname -m)"
[ "$ARCH" = arm64 ] && ARCH=aarch64

case "$SYSTEM" in
    Linux)
        if [ -n "${TERMUX_VERSION:-}" ] || [ "${PREFIX:-}" = /data/data/com.termux/files/usr ]; then
            SYSTEM=android
        else
            SYSTEM=linux
        fi
        ;;
    Darwin) SYSTEM=darwin ;;
    *) echo "Unsupported platform: $SYSTEM $ARCH" >&2; exit 1 ;;
esac

run() {
    tmp_dir="${TMPDIR:-${PREFIX:+$PREFIX/tmp}}"
    tmp_dir="${tmp_dir:-/tmp}"
    mkdir -p "$tmp_dir" 2>/dev/null || true
    [ -d "$tmp_dir" ] && [ -w "$tmp_dir" ] || { echo "Temporary directory not writable: $tmp_dir" >&2; exit 2; }

    umask 077
    tmp_exe="$(mktemp "$tmp_dir/🐚︎XXXXXXXXXXXX")" || { echo "Could not create launcher in $tmp_dir" >&2; exit 1; }
    trap 'rm -f "$tmp_exe"' EXIT

    tail -c "+$(($1 + 1))" "$ME" | head -c "$2" > "$tmp_exe"
    [ -s "$tmp_exe" ] || { echo "brot: failed to extract launcher into $tmp_exe from $ME" >&2; exit 3; }
    chmod 700 "$tmp_exe"
    exec "$tmp_exe" "$ME" "$POOL_OFFSET" "$POOL_LENGTH" "$@"
}

POOL_OFFSET={{.PoolOffset}}
POOL_LENGTH={{.PoolLength}}

case "$SYSTEM/$ARCH" in
    linux/x86_64)    run {{.BrotLinuxX86_64Off}} {{.BrotLinuxX86_64Len}} "$@" ;;
    linux/aarch64)   run {{.BrotLinuxAarch64Off}} {{.BrotLinuxAarch64Len}} "$@" ;;
    android/aarch64) run {{.BrotAndroidAarch64Off}} {{.BrotAndroidAarch64Len}} "$@" ;;
    darwin/x86_64)   run {{.BrotDarwinX86_64Off}} {{.BrotDarwinX86_64Len}} "$@" ;;
    darwin/aarch64)  run {{.BrotDarwinAarch64Off}} {{.BrotDarwinAarch64Len}} "$@" ;;
    *) echo "Unsupported target: $SYSTEM/$ARCH" >&2; exit 1 ;;
esac
```
