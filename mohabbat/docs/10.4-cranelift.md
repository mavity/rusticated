# Overlaid Wasmtime (`min-platform` + Cranelift JIT) Movable Runtime Specification

## 1. Objective & Architectural Mandate

This specification defines the execution engine layer for Mohabbat-next: embedding **Wasmtime `49.0.5**` in its `#![no_std]` / no-OS **`min-platform`** configuration with **in-process Cranelift JIT compilation enabled**, packaged as an OS-blind, relocation-free movable machine-code slice (`x86_64-unknown-none` and `aarch64-unknown-none`).

**Architectural Reality & Binding Requirement:**

* Upstream Wasmtime (`49.0.5`) supports `#![no_std]` / no-OS (`min-platform`) out of the box **only** when the `cranelift` feature is disabled (AOT `.cwasm` deserialization or Pulley bytecode execution). Enabling `cranelift` in stock Wasmtime pulls in `std` via `wasmtime-environ/compile`, `gimli/std`, `object/std`, and OS SEH unwind registration (`RtlAddFunctionTable`) in `CodeMemory`.
* Therefore, this specification **mandates a bounded, deterministic overlay pass** in `build/cranelift_overlay.go` that strips `std` and OS-specific unwind calls from the `49.0.5` Wasmtime/Cranelift crate graph while preserving 100% of Wasmtime's WebAssembly validation, Cranelift code generation, `Store`, `Instance`, `Linker`, and `Module::new` pipeline.
* The outer **Runtime slice** (`[0x00000 .. +N)`) remains strictly compliant with `10.6-native-rusticated-abi.md`: zero dynamic linker, zero load-time relocations (`llvm-readobj -r` clean), zero OS TLS, strict $W \oplus X$ (`RX`), and zero-argument entry at byte offset `0`. Inside that confinement, Wasmtime allocates its own private heap and code arenas via `PalAbiTable`, compiles `brain.wasm` into an in-memory ELF `CodeMemory` container, resolves its own internal relocations in RAM, and executes guest code.

**Scope for Single-Instance `brain.wasm`:**

* **In scope:** Full Core WebAssembly + post-MVP ISA compliance (`wasmparser::Validator`, multi-value, bulk memory, reference types, SIMD, `memory.grow`), in-process Cranelift JIT (`Module::new`), `Linker` host bindings for the 45-function Rusticated WASM ABI (`"env"`), and explicit software bounds checks (`Config::signals_based_traps(false)`).
* **Explicitly deferred:** Garbage collection (`gc-null` stub only if required by internal `49.0.5` trait bounds), fuel/epoch interruption, multi-instance orchestration, and offline `.cwasm` caching.

## 2. System Architecture & Layer Boundaries

```text
┌─────────────────────────────────────────────────────────────────────────┐
│ PAL (OS-specific movable slice: Windows IOCP / Linux io_uring / macOS)  │
│  • Populates PalAbiTable [-0x20000 .. -0x10000) & zeroes [-0x10000)     │
│  • Synchronous: alloc_mem, protect_mem, free_mem, flush_icache          │
│  • Async reactor: harvests Overlapped completions, calls Runtime @ 0    │
└────────────────────────────────────┬────────────────────────────────────┘
                                     │ extern "C" fn() at byte offset 0
                                     ▼
┌─────────────────────────────────────────────────────────────────────────┐
│ Movable Runtime Slice (Overlaid Wasmtime `min-platform` + Cranelift JIT)│
│  ┌───────────────────────────────────────────────────────────────────┐  │
│  │ 1. `wasmtime_*` Platform C-ABI Bridge (`runtime/src/wasmtime_pal`)│  │
│  │    • wasmtime_mmap_{new,remap} / munmap -> abi().alloc_mem / free │  │
│  │    • wasmtime_mprotect -> abi().protect_mem + abi().flush_icache  │  │
│  │    • wasmtime_tls_{get,set} -> globals().wasmtime_tls_ptr         │  │
│  │    • wasmtime_setjmp / longjmp -> minimal arch-specific asm       │  │
│  ├───────────────────────────────────────────────────────────────────┤  │
│  │ 2. Wasmtime Engine (`Engine`, `Store<HostState>`, `Linker`)       │  │
│  │    • Cold Boot (Call #1):                                         │  │
│  │      - Builds Engine (`signals_based_traps(false)`, no guard pages)│  │
│  │      - Compiles `abi().wasm_bytes` via `Module::new` (in-RAM ELF) │  │
│  │      - Links 45 `"env"` adapters (`wasm_env.rs`) via `Linker`     │  │
│  │      - Instantiates module, caches `Instance` & `TypedFunc` (`run`)│  │
│  │    • Warm Re-Entry (Call #2..N):                                  │  │
│  │      - Invokes cached `run.call(&mut store, ())`                  │  │
│  │      - Unwinds and returns to PAL when goroutines park on I/O     │  │
│  └───────────────────────────────────────────────────────────────────┘  │
└─────────────────────────────────────────────────────────────────────────┘

```

## 3. Mandatory Overlay & Build Specification (`build/cranelift_overlay.go`)

`build/cranelift_overlay.go` fetches the pinned `49.0.5` crates from Cargo's registry cache, applies the four mandatory patches below into `runtime-cranelift-overlay`, and wires them via `[patch.crates-io]`:

### 3.1 Four Mandatory Overlay Patches

1. **`wasmtime-environ` (`=49.0.5`) — Strip `std` from `compile`:**
* Remove `std` activation from the `compile` feature in `wasmtime-environ/Cargo.toml` so `wasmtime-environ` compiles strictly `#![no_std]` + `alloc`.
* Replace `std::collections` imports in `compile`-gated modules with `hashbrown` / `alloc::collections`, and `std::error::Error` with `core::error::Error`.


2. **`wasmtime-internal-cranelift` (`=49.0.5`) — `#![no_std]` Object & Debug Info:**
* Configure `gimli` and `object` with `default-features = false` (`object` with `features = ["read_core", "write_core", "elf"]` so in-memory ELF emission and parsing remain functional without `std::fs` or `std::io`).
* Disable `std` features on `anyhow` and `thiserror` across the overlay workspace.


3. **`wasmtime` (`=49.0.5`) — `min-platform` JIT Selection & SEH Stubbing:**
* Force `vm::sys::custom` (`min-platform` C-ABI backend) on `target_os = "none"` even when the `cranelift` feature is active.
* Stub out Windows `RtlAddFunctionTable` / `RtlDeleteFunctionTable` unwind registration calls inside `CodeMemory` (`vm::code_memory`) as no-ops, since the Runtime executes in signal-free mode (`signals_based_traps(false)`) without OS SEH unwinding.


4. **Static `.rodata` Zero-Relocation Hygiene:**
* Patch static empty control tables (`hashbrown` empty tag tables, `bumpalo` empty chunks, and any static pointer tables in Cranelift/Wasmtime) to route through heap-initialized slots anchored in `RuntimeGlobals` (`-0x10000`).
* **Hard Build Gate:** Every build must pass `llvm-readobj -r` on the linked Runtime ELF prior to flat binary extraction with **zero dynamic/load-time relocations** (`R_X86_64_NONE` / `R_AARCH64_NONE` only, or empty relocation sections). (Relocations created dynamically by Wasmtime inside its heap-allocated `CodeMemory` ELF buffer are resolved in RAM by Wasmtime itself and do not affect the outer slice.)



### 3.2 `runtime/Cargo.toml` Configuration

```toml
[dependencies]
wasmtime = { version = "=49.0.5", default-features = false, features = [
    "runtime",
    "cranelift",
] }

[features]
default = ["x86_64"]
x86_64 = ["wasmtime/arch-x86_64"]
aarch64 = ["wasmtime/arch-aarch64"]

```

## 4. `min-platform` C-ABI Bridge (`runtime/src/wasmtime_pal.rs`)

In `vm::sys::custom` mode, Wasmtime delegates all host virtual-memory, protection, TLS, and trap-unwind operations to `extern "C"` symbols. Because the Runtime is a self-contained movable slice with no external dynamic linker, `runtime/src/wasmtime_pal.rs` defines every required symbol internally via `#[unsafe(no_mangle)] pub unsafe extern "C" fn` and forwards it to `PalAbiTable` (`-0x20000`) and `RuntimeGlobals` (`-0x10000`):

| `min-platform` Symbol | Contract & Implementation over `PalAbiTable` / `RuntimeGlobals` |
| --- | --- |
| `wasmtime_page_size() -> usize` | Returns `65536` (64 KiB granularity, aligning cleanly across 4 KiB x86/Linux, 16 KiB Apple Silicon, and 64 KiB Windows pages). |
| `wasmtime_mmap_new(size, prot_flags, &mut ret) -> i32` | Maps `prot_flags` to `MEM_READWRITE` or `MEM_CODE_JIT_RW` (when executable permissions are requested) and calls `abi().alloc_mem(size, 65536, flags)`. |
| `wasmtime_mmap_remap(addr, old_size, new_size, can_move, &mut ret) -> i32` | Allocates `new_size` via `abi().alloc_mem`, copies `min(old_size, new_size)` bytes when `can_move != 0`, and releases `addr` via `abi().free_mem`. |
| `wasmtime_munmap(ptr, size) -> i32` | Calls `abi().free_mem(ptr, size)` and returns `0`. |
| `wasmtime_mprotect(ptr, size, prot_flags) -> i32` | Transitions page permissions via `abi().protect_mem(ptr, size, mapped_flags)`. Whenever executable permission (`RX`) is applied, immediately calls `abi().flush_icache(ptr, size)` before returning. |
| `wasmtime_tls_get() -> *mut u8` | Reads `globals().wasmtime_tls_ptr` via negative PC-relative offset (`-0x10000`) — zero OS TLS (`.tdata`/`.tbss`). |
| `wasmtime_tls_set(ptr: *mut u8)` | Writes `ptr` into `globals().wasmtime_tls_ptr` at `-0x10000`. |
| `wasmtime_init_traps(handler)` | Records `handler` in `globals().wasmtime_trap_handler` without registering OS signal/VEH handlers. |
| `wasmtime_memory_image_new(...)` / `map_at` / `free` | Sets `*ret = core::ptr::null_mut()` and returns `0` (disables fd-backed copy-on-write memory images; Wasmtime initializes linear memory directly from data segments). |
| `wasmtime_setjmp` / `wasmtime_longjmp` | Minimal ISA-specific inline assembly saving/restoring callee-saved registers (`rbx, rbp, r12..r15, rsp, rip` on `x86_64`; `x19..x30, sp, d8..d15` on `aarch64`) for trap unwinding without a C runtime. |

## 5. Signal-Free Engine Configuration & `Overlapped` Memory Safety

On cold boot (first invocation of byte offset `0`), the Runtime initializes `wasmtime::Config` in `RuntimeGlobals` (`-0x10000`) with strict signal-free and single-threaded settings:

```rust
let mut config = wasmtime::Config::new();
config.signals_based_traps(false);                 // Emit explicit software bounds checks
config.memory_guard_size(0);                       // Zero MMU guard pages
config.memory_reservation(MAX_GUEST_LINEAR_BYTES); // Reserve fixed guest span upfront
config.memory_may_move(false);                     // Prevent base relocation while Overlapped I/O is in flight
config.parallel_compilation(false);                // Single-threaded compilation
config.cranelift_opt_level(wasmtime::OptLevel::None); // Fast startup JIT

```

**Critical `Overlapped` Pointer Stability Invariant:**

* Because the PAL writes asynchronous completion headers and I/O buffers directly to 64-bit native addresses inside guest linear memory while the Runtime call stack is unwound, the base address of guest linear memory (`mem_base`) **must never relocate** across `memory.grow` while any `Overlapped` operation is outstanding.
* Setting `memory_reservation(MAX_GUEST_LINEAR_BYTES)` (matching `brain.wasm`'s declared maximum memory pages, or a bounded ceiling such as 256 MiB / 512 MiB) with `memory_may_move(false)` guarantees that `memory.grow` commits additional pages in place without changing `mem_base`.

## 6. Rusticated WASM ABI (`"env"`) Adapter (`runtime/src/wasm_env.rs`)

All 45 functions of the **Rusticated WASM ABI** (`"env"` namespace, matching slots `2..46` of `PalAbiTable`) are registered on `wasmtime::Linker<HostState>` via `Linker::func_wrap`:

1. **Strict Namespace Isolation:** Reject any module importing `wasi_snapshot_preview1` or non-`"env"` modules at instantiation time.
2. **32-Bit Guest Span Validation & Translation:**
* Every adapter resolves the guest's exported `"memory"` (`wasmtime::Memory`) from `Caller<'_, HostState>` and validates every `(offset: u32, len: u32)` pair via `offset.checked_add(len)` against `memory.data_size(&caller)`.
* Out-of-bounds spans immediately invoke `abi().host_panic` (or return a Wasmtime `Trap`).
* Valid non-zero offsets are translated to `memory.data_ptr(&mut caller).add(offset as usize)` before invoking the corresponding native function pointer in `PalAbiTable` (`[-0x20000 .. -0x10000)`).


3. **Cold Boot vs. Warm Re-Entry Lifecycle:**
* **Call #1 (Cold Boot):** `globals().initialized == false`. The Runtime builds the `Engine`, compiles `abi().wasm_bytes[..abi().wasm_len]` via `Module::new`, registers all `"env"` functions on `Linker`, instantiates the module, caches `(Store, Instance, TypedFunc<(), ()>)` (`run` export) in heap memory rooted in `RuntimeGlobals` (`-0x10000`), sets `globals().initialized = true`, and invokes `run.call(&mut store, ())`.
* **Call #2..N (Reactor Re-Entry):** `globals().initialized == true`. The Runtime retrieves the cached `Store` and `TypedFunc` from `RuntimeGlobals` and immediately invokes `run.call(&mut store, ())`. When all guest goroutines park on pending `Overlapped` operations, `run` unwinds cleanly and byte offset `0` returns to the PAL.

## 7. Phased Implementation & Verification Gates

| Phase | Deliverable | Hard Verification Gate |
| --- | --- | --- |
| **Phase 1: Mandatory Overlay & `no_std` Build** | Implement the four `49.0.5` patches in `build/cranelift_overlay.go` (`wasmtime-environ`, `wasmtime-internal-cranelift`, `wasmtime` `vm::sys::custom` + `CodeMemory` SEH stub, and `.rodata` heap tables) and update `runtime/Cargo.toml`. | `cargo build --target x86_64-unknown-none` and `aarch64-unknown-none` succeed; `llvm-readobj -r` confirms **zero load-time relocations** in the outer Runtime ELF. |
| **Phase 2: `wasmtime_pal.rs` & In-Memory JIT Smoke Test** | Implement all `wasmtime_*` C-ABI symbols in `runtime/src/wasmtime_pal.rs` (`mmap_*`, `mprotect` + `flush_icache`, `tls_*` in `RuntimeGlobals`, `setjmp`/`longjmp`). | A standalone `.wasm` test module compiles via `Module::new(&engine, bytes)`, executes linear memory loads/stores and `memory.grow`, and returns cleanly on Windows, Linux, and macOS. |
| **Phase 3: `"env"` Linker Adapters (`wasm_env.rs`)** | Register all 45 Rusticated WASM `"env"` imports on `wasmtime::Linker` with bounds validation and `PalAbiTable` forwarding. | WASM ports of the `Hello World` and `--file-io-test` conformance harnesses pass across async exit-and-re-entry cycles. |
| **Phase 4: Single-Instance `brain.wasm` Cutover** | Remove the legacy manual translator in `runtime/src/jit.rs`; wire `brain.wasm` (`GOOS=wasip1` `rusticated-go`) cold boot and warm re-entry end-to-end. | Full `brain.wasm` boots, runs concurrent goroutines over async PAL I/O, and exits cleanly with zero temp files or OS signals. |
