# Mohabbat Redesign Fortification Plan (Zig + `zwasm`)

To keep low-level contracts, zero-relocation invariants, and startup latency regressions locked down across all platforms, every layer is protected by automated unit and artifact-invariant tests:

### 1. Builder & Assembly Tests (`mohabbat-next/build/build_test.go`)
- MZ/PE header validation, DOS stub (`<= 59` bytes, LF-only), and `bootstrap.sh` template rendering.
- `MHBTPOOL` TOC packing/lookup and single-blob Zstandard round-trip integrity, plus `MHBTTAIL` 24-byte EOF trailer verification.
- Synthetic polyglot bundle assembly and WSL/Bash handoff execution.

### 2. Freestanding Zig Runtime & PAL Unit Tests (`zig test`)
- **Memory intrinsics**: `memcpy`, `memmove` (overlapping forward & backward), `memset`, `memcmp` correctness and word/SIMD-width throughput.
- **In-process `std.mem.Allocator`**: alignment (`8`, `16`, `64`, `4096`), power-of-2 bin reuse, large-block handling without `VirtualAlloc`/`mmap` churn on every `align > 16` or `> 128 KiB` alloc, and OOM handling.
- **`zwasm` `"env"` host adapter**:
  - Rejects `wasi_snapshot_preview1` / non-`"env"` imports at instantiation.
  - Bounds-checks every `(offset, len)` guest span (`offset + len <= guest_mem_len`) and traps cleanly on overflow/OOB.
  - Verifies fixed-base linear memory growth (`Overlapped` pointer stability) and cold boot + warm re-entry (`run` / `_initialize` / `_start`).
- **`comptime` ABI layout invariants**: exact sizes and byte offsets for `PalAbiTable` (48 slots = 384 bytes), `Overlapped` (24 bytes), `ProcessSpawnOverlapped` (64 bytes), `AbiStat` (112 bytes), and `AbiPlatformInfo` (1264 bytes).

### 3. C# Windows Host Unit Tests (`MohabbatNext.exe --unit-test`)
- `WindowsPlatformHost` struct layout and offsets (80 bytes, `PrefixAbiOffset = 0x20000`).
- Architecture detection (`x86_64` / `aarch64`).
- `MHBTPOOL` / `MHBTTAIL` Zstandard decompression and entry lookup (`platform-windows-*`, `hello-*`, `fileio-*`, `runtime-*`).
- `PalAbiTable` field offset checks (48 slots).

### 4. Linker Script & Binary Artifact Invariant Tests (`mohabbat-next/test`)
- Automated `llvm-readobj --relocs` and section inspection on every flat slice (`payload`, `pal/windows`, `pal/unix`, `runtime-{x86_64,aarch64}`):
  - For `payload`, `pal/windows`, and `pal/unix`: **0 relocations** (no `R_*_RELATIVE`, no `.rela.*`/`.rel.*`), and **0 `.data`**, **0 `.bss`**, **0 `.got`**, **0 `.plt`**, **0 `.data.rel.ro`** sections.
  - For `runtime-{x86_64,aarch64}` (`zwasm`): **0 text relocations**, **0 `.data`**, **0 `.got`**, **0 `.plt`**, and `.data.rel.ro` + `.bss` + relocation-offset table within the `-0x10000` RW prefix size gate (`<= 32 KiB`).
  - **0 TLS** and **0 undefined symbols** across all slices (inspected prior to any `/DISCARD/`).
- Standard vegetable acceptance matrix (`demo-go`, `kabibi`, and `test-matrix.txt` targets) on Windows and WSL/Linux, including startup-latency budgets.
